# 课程与培养方案

先读取 `degree_plan` 的分组、学分要求和备注，再读取 `course_history`、相关课程和用户档案。课程记录缺失、完成状态未确认时，请用户补充已修课程；不把平台出现的课程等同于已通过的课程。培养方案年份是方案版本，不用于推断入学年份。

围绕用户未来方向查询 `study_course_search(q=课程代码或名称)`，再用返回的 syllabus_id 读取教学大纲、先修要求与课程内容。目录不证明未来某学期一定开课，建议学期不证明当前可以选课。

分别说明学校明确要求、需要确认的条件和根据兴趣提出的建议。优先给出少量有依据的课程与修读顺序、预计负担和替代选择，引用学校要求的原文；方向或历史不充分时提出具体问题。建议不代替教务审核，不替用户选课。
