# 作业与复习计划

先查询 `assignments`（pending=true）、`timetable` 和必要的 `profile`。只把明确开放且未提交的作业列为确定待办；状态未知时标记待确认。统一使用北京时间，区分截止时刻、考试开始时刻、活动时段与仅有节次的课程。

待办数量使用作业查询返回的完整统计来源 summary，具体记录以 pending 字段为准。截止已过但来源仍显示开放、或者截止时间未提供，都不能单独从待办中排除；逾期、缺少时间与是否列入待办分别说明。返回记录受分页或关键词限制时，不用当前页长度代替总数。来源同步失败时说明使用缓存。

优先安排临近截止和依赖前置知识的工作，避开实际课程与活动。工作量未知时给出估计并说明依据；可用时间不足时列出冲突和需要用户决定的取舍。用日期、时间段、具体任务和完成标准表达计划，预留检查与提交时间。没有课程日期或节次钟点映射时，不声称已经排除课程冲突。

需要理解题目时先加载文件阅读技能，读取作业和同课程课件，给出“复习哪些页 → 尝试哪部分 → 怎样检查”的顺序。计划用于学习辅助，保存或导航仅使用已授权的工作台工具。

用户明确要求落地日程时，查询目标周后使用 study_schedule_edit。只讨论方案时保留在回答中；目标或单次/后续范围不明确时先澄清。课程只有节次时用日期与节次安排，不能猜钟点；调课、请假、停课与恢复保留原教务课表。读取实际成功回执，报告受影响次数和已检查周的冲突；时间不完整时不能断言无冲突。
