# 首页学习助手

独立的首页聊天与原生 Harness 插件，模块 ID 为 `academic-assistant`。在设置中启停该模块即可控制首页入口和工具；模型与 Key 使用共享 AI 服务。工具通过已有模块公开 API 按需读取课程、作业、时间表、通知、邮件、已有课程记录与培养方案，检索课程资料和录播原文，读取 PDF／PPTX 页级文字，并查询教务课程目录与大纲。回答返回可核对的来源与原文片段，可按用户要求打开工作台页面。

## 接口与资料

前缀为 `/api/v1/modules/academic-assistant`。`GET/POST/DELETE /chat` 读取、发送和清除聊天；`GET/PUT/DELETE /profile` 管理本机学习档案；`GET /activity` 查看当前任务的工具进度，`GET /presets` 返回 `{items:[{label,prompt}]}` 常用问题。用户档案包含专业、入学年份、未来方向、每周可用学习时间与备注，培养方案作为带来源的学业记录单独保存。聊天按共享账号版本隔离，档案和学业记录按已验证的 IDS 账号隔离。

原生工具由 `harness/` 注册，使用一次任务有效的本机令牌访问 `/tools/query`、`/tools/search`、`/tools/document`、`/tools/course-search`、`/tools/navigate`、`/tools/remember` 和 `/tools/finish`。令牌通过服务端 `plugin_env` 注入运行时，不进入模型提示；接口仅在该任务存续、账号版本相同时接受调用。工具返回的引用保存在任务内，模型先通过 `study_finish` 提交引用和 `insufficient_context`，后端核对实际来源及字词顺序，允许排版空白差异，保留引用片段的连续原文。校验失败由模型在本次任务中修正，通过后再以普通 assistant 消息流式生成 Markdown 正文。完整任务成功且账号版本仍一致时才保存聊天；最终事件附上已核对的引用卡片。`study_finish.text` 为可选兼容字段，提供时作为最终正文。

学习规划根据明确的待办、截止时间、已公开的作业状态和用户可用时间提出建议，估计工时与学校要求分别说明；课件引用显示真实页码。选课建议结合历史修读记录、培养方案、课程目录／大纲和用户方向，区分学校要求与建议，学期实际开课需要另行核对。用户明确要求记录本次消息中的个人信息时，工具核对原文后保存；用户也可在档案表单中编辑或清除。

PDF、PPTX 和 UTF-8 文本按需通过 Blackboard／Gradescope 文件 API 下载及解析。单文件至多 30 MB，PDF／PPTX 至多 1000 页，PPTX 文字 XML 合计至多 40 MB；每页提取至多 20000 字符，每次返回至多 12 页、每页片段至多 6000 字符。PPTX 页码遵循演示文稿实际顺序。扫描页／图片和旧版 `.ppt` 暂需在原文件查看。提取文字缓存在本模块 `data_dir/documents/<账号组合版本>/`，由来源更新时间区分版本，引用保留原文件入口。

首页显示资料会发送至 DeepSeek 的说明。助手按问题读取课程、作业与 DDL、时间表、课件文字、录播、讨论、相关通知／邮件、已有课程、培养方案及学习档案；学校凭据和会话由原服务维护，短期工具令牌留在本机。当前工具版本最近 8 条消息的文本和个人偏好作为连续对话上下文，每条历史文本至多 2500 字符；本机保留最近 60 条消息。历史按所有共享服务的账号版本隔离，个人档案与学校记录按 IDS 隔离。清空对话、清除档案分别通过首页按钮操作；完整模块文件可通过设置清除模块数据。

来源缓存、教师课件及工具输出作为学习资料处理。页面操作仅限工作台分类导航，文件解析与建议不改变原站作业或选课状态。

## 请求与结果

发送 `POST /chat`，例如 `{"message":"核对本周未完成作业，结合截止时间与课表安排学习。"}`。`message` 为 1–8000 字符。返回助手消息 `{"role":"assistant","text":"…","citations":[{"source_id":"…","title":"…","quote":"…","url":"…","page":3,"download_url":"…"}],"navigation":null,"tools":[{"name":"study_query","is_error":false}],"model":"deepseek-flash","created_at":"…"}`；引用仅保留实际可用字段。空问题或参数越界为 422，账号切换或 AI 未配置为 409；运行时失败或尚未提交已校验回答为 502。来源未连接等工具错误交给模型解释，缺少资料时可返回明确说明。

`PUT /profile` 接收完整个人档案；专业至多 120 字、方向 1200 字、备注 4000 字，`cohort_year` 为 2000–2100 或 null，`weekly_hours` 为 0–168 或 null。`GET /profile` 返回 `{profile,academic:{plan_title?,updated_at?}}`。培养方案在实际查询时更新。

首页使用 `POST /chat/stream`，请求体同 `/chat`，响应为 `application/x-ndjson`，每行一个 JSON 事件，按顺序处理：

| type | 字段与行为 |
| --- | --- |
| `activity` | `steps:[{name,label,status}]`，准备或工具执行状态 |
| `reset` | 开始新的模型输出尝试，清空当前临时正文 |
| `delta` | `text`，引用核对通过后的正文增量；不发送推理或工具参数 |
| `complete` | `message`，与普通 `/chat` 的助手消息一致，替换临时正文并显示引用 |
| `error` | `status`、`detail`，任务失败；保留输入，聊天历史保持原状 |

只有 `complete` 表示回答完成。连接提前结束时前端提示重试；停止生成或离开页面会取消请求、通知运行时结束任务，并等待后台释放工作区和一次性令牌。初始化或安装依赖期间的停止在当前初始化步骤完成后生效。中断的半段正文不保存到历史。

工具查询支持关键词、课程与分页，默认返回 30 项、至多 60 项；材料／讨论检索默认 12 项、至多 30 项。录播原文查询返回已有转写片段和时间点，不下载录播视频。工具步骤达到 24 次后保留最终回答提交入口，其他操作需缩小范围继续对话。

## 开发与验证

前端复用 Nord 变量、共享组件与注入上下文，离开页面取消流式请求、待渲染帧并移除样式。后端任务通过官方 `context.ai.run(..., plugins=["academic-assistant"], on_event=..., cancel_event=...)` 执行，使用期间遵循模块请求计数；任务结束释放一次性令牌，模块停止释放内存任务。共享 Markdown 渲染器使用本机提供的 markdown-it 15.0.3，关闭 HTML，沿用解析器的链接校验，图片仅显示描述。合成检查覆盖中文跨字节分片、Markdown 安全、引用核对、取消任务及失败后保留历史；真实 Harness 检查确认文字在模型响应结束前到达。

宿主在 `.private/runtime/tmp/harness-*/workspace/` 创建任务工作区。原生插件用 `process.cwd()` 读写其中的 `study-<序号>-<工具>.json`，保存工具参数、实际读取结果与已核对的回答，供当前任务分析使用；令牌不写入文件。任务结束工作区自动清理，长期对话、档案与课件文字缓存由本模块的 Store 和 data_dir 保留。工作区及其他私有运行数据均由 Git 忽略。

使用合成 API 与文档验证工具、引用、账号隔离和个人信息更新；使用官方运行时验证实际工具调用。真实服务验收由用户在设置连接后进行。

## 校园规则与技能

`harness/AGENTS.md` 定义校园学习场景、简明沟通、证据与个人信息边界；`server/instruction.md` 约定工具和回答校验；`harness/prompts.json` 提供首页常用问题。`harness/skills/` 内的文件阅读、作业规划与培养方案技能通过官方注册表及 `skill` 工具按需加载。新增技能遵循相同结构，使用工作台现有工具，随插件启停。规则不包含开发环境要求。

首页上方显示课程、作业、资料摘要，近期安排按需展开；对话区单独滚动，输入框固定在对话底部。阅读旧消息时暂停跟随，点击“回到最新回复”继续跟随生成。长回答支持标题、列表、表格、引用和代码块；表格、代码在内容区内滚动，回答及代码可复制。同一份文件的引文合并展示并标注编号、页码与原文件入口。学习档案按需打开，模型链接直接进入统一 AI 设置。已有本机聊天记录保留，连续对话使用当前工具版本写入的消息。底层运行与权限边界见 [AI 文档](../../docs/AI.md)。
