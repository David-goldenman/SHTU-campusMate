# E 云课堂

通过共享学校 IDS 登录，只读同步当前账号可见的课程、课件、公告和作业。课程中心按学期合并课程，作业管理及首页助手使用同一份提交状态和待办统计。

## 接口

- `GET /api/v1/modules/ecourse/snapshot`：离线读取标准课程数据包及同步状态。
- `POST /api/v1/modules/ecourse/sync`：202 启动后台同步；重复调用复用当前任务。

课程来自原站 `POST /api/my-courses` 查询，课件、作业和公告分别读取课程的 `coursewares`、`homework-activities`、`bulletins` GET 接口。每页 100 条，最多 100 页，校验分页总量及重复标识。只保存课件说明和附件名称、类型、大小，原站链接打开课程栏目；不下载文件，不提交作业、不上传、不发布公告、不标记原站已读或学习进度。

原站 `submitted` 布尔字段确认是否提交；有可公布的本人分数才标记已评分，缺少提交证据保留上次状态并标记待核实，无历史时为未知。开放性根据原站发布、关闭和开始时间判断，不以截止时间推断关闭。公告、课件或作业某一栏读取失败时保留该栏缓存并标记过期，不清空成功数据。登录失效交给共享认证恢复。账号切换隔离缓存，停用取消并等待任务结束。

数据保存在本模块 `context.store`，凭据只由共享认证的 Vault 管理。认证目标为 `ecourse`；不会建立独立登录存储。检查入口：`python modules/ecourse/checks/check_ecourse.py`，仅使用合成 HTTP 响应。
