# Piazza 讨论

使用共享 `piazza` 认证。`GET /snapshot`、`POST /sync` 提供可见课程与每门课最近更新的最多 50 条帖子，metadata 明确该范围。接受课程目录的对象或数组形式，异常帖子独立提示，单门课读取失败保留该课程讨论。

`GET /post?course_id=平台课程ID&post_id=平台帖子ID` 读取当前列表中的正文及嵌套回复，并把已读正文缓存到公开快照供课程与 AI 使用。回复限制 500 条；远端 HTML 转成纯文本，展示使用安全输出。`stop(context)` 结束同步；项目检查运行本模块的合成目录、帖子和嵌套回复验证。
