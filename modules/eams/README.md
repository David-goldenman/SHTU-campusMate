# 教务系统

模块 `eams` 提供考试、专业培养方案、课程目录与教学大纲。使用共享 IDS 的 `timetable` 登录目标；首页学习助手通过公开接口按需读取资料。

前缀为 `/api/v1/modules/eams`。

| 接口 | 用途 |
| --- | --- |
| `GET /snapshot` | 当前考试、已有课程记录与本专业培养方案 |
| `POST /sync` | 启动同步，返回 202 |
| `GET /exams?semester_id=&batch_id=` | 指定学期与可选批次的考试；当前学期使用缓存 |
| `GET /course-search?q=&page=1` | 按课程名或代码查询目录，q 为 1–160 字符，page 为 1–100 |
| `GET /course-info?syllabus_id=` | 根据正整数 ID 读取教学大纲，正文至多 24000 字符 |

快照使用校园数据契约。`assignments` 为考试，包含名称、日期、开始时间、时间段、地点、批次、状态与来源，`due_at` 表示考试开始时间。`metadata` 公开学期目录、学生标识、考试批次与 `study_plan{title,groups,requirements,notes}`。培养方案保留课程分组、学分、建议修读学期、必修标志和学校原文要求。

`courses` 保留已有记录的课程 ID、名称、代码、学期、学分、类别和来源；公开快照仅投影这些学习规划所需字段。已有本地原始缓存保留，当前同步读取考试与培养方案。课程目录和大纲按查询实时读取，不代表未来学期已确定开课。已有记录也不能替代修读完成状态的确认。

同步依次读取考试首页、学期目录、考试表与培养方案。页面之间等待 1.2 秒；遇到访问频繁提示等待 4 秒，最多重试 3 次。单板块的结构或 403/404 错误保留该板块缓存，登录失效交给共享认证恢复。跨学期考试和目录查询在读取前后核对账号版本，账号切换返回 409。

页面直接显示考试，培养方案按课程组展开。学习问答统一由首页助手负责。运行 `python modules/eams/checks/check_eams.py` 检查合成解析、公开字段、板块错误与账号切换。
