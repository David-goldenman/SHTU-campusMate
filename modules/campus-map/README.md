# 校园地图

提供本地校园建筑图、当天安排的时间／事项／教室与建筑定位，以及有校方出处的电梯位置说明。独立分类为 `campus-map`，通过模块清单注册，框架无需增加业务分支。

## 数据与范围

`data/places.json` 的 65 个建筑／校门轮廓及校园边界取自[学校官方地图](https://map.shanghaitech.edu.cn/)在 2026-10-17 返回的公开数据，保留其 BD-09 坐标；仅保存建筑名称、类别、几何、别名和官方链接。其中 5 处校门提供短名称与地址，可直接点击定位。地图在本地绘制，打开页面不加载第三方地图脚本，也不向校外发送个人日程。

建筑图支持缩放、平移、搜索、键盘操作、展开地图和当天地点标记。楼名以 14px 屏幕字号显示，不随全图缩放变小；标签按所选地点、校门、当天安排、常用建筑的顺序避让，放大后显示更多楼名，也避让地图操作按钮。它是建筑级定位，不把建筑中心解释成教室门口或电梯精确坐标。详细校内步行导航可打开选定建筑的官方地图入口。

`data/osm-basemap.json` 单独保存道路、步行道、水系和绿地，来自 [OpenStreetMap 校园范围公开数据](https://api.openstreetmap.org/api/0.6/map?bbox=121.5835,31.1745,121.5968,31.1835)，查阅于 2026-10-17。本次使用参考 HTML 的地图分层思路，并重新下载覆盖整个校园的底图，不包含参考文件中的活动目标或测距记录。271 条道路线段与 68 个景观要素仅用于方位显示；不由此推断道路开放、无障碍通行或地下路线。

OSM 衍生数据按 [ODbL 1.0](https://www.openstreetmap.org/copyright) 提供，版权为 © OpenStreetMap contributors，地图上保留可见署名。原始 WGS84 坐标在离线导入时通过 [coordtransform 2.1.2](https://github.com/wandergis/coordtransform)（MIT）依次转为 GCJ-02、BD-09，与校方建筑图对齐，文件保留转换说明和 OSM 要素 ID。转换只用于底图显示，不作为测绘精度保证；运行时不需要坐标转换库或新依赖。OSM 文件与校方建筑数据分开保存，各自保留来源。

电梯资料目前覆盖图书馆与创意与艺术学院，共三条楼内位置说明。地图按所属建筑标记，详情保留楼层、位置原文依据和出处链接；查阅日期不表示现场核验，未收录不表示没有电梯。没有完整室内路网，不推断无障碍通行条件、开放状态、停靠楼层或地下车库体育课路线。图书馆的两条位置说明不推断为两台独立电梯。

- 图书馆一楼东门电梯口：[其他设施](https://library.shanghaitech.edu.cn/3992/list.htm)。
- 图书馆一楼大厅中部电梯口：[小组讨论室](https://library.shanghaitech.edu.cn/2018/0814/c3989a31486/page.htm)。
- 创艺学院东南角电梯、地下车库 C/B 区交界附近的进入说明：[联系我们](https://sca.shanghaitech.edu.cn/2018/0803/c4123a31066/page.htm)。

地下体育场地路线尚未核实，按本次需求暂不实现。已有课表中的体育馆 B107 等地点仍可定位到体育馆，教室名称保留来源原文。

## 接口与日程

前缀 `/api/v1/modules/campus-map`：

- `GET /places` 返回上述公开建筑、电梯说明及来源元数据，以及 `basemap` 内的 OSM 道路与景观数据。
- `GET /day?date=YYYY-MM-DD` 默认北京时间今天，仅经公开 `context.api('timetable','/schedule?week_start=...')` 读取所选日期的日历。返回日期、精简日程、来源状态、更新时间和问题提示；不触发学校同步、AI 或任何写入。读取前后检查账号版本，切换账号返回 409。

课程取消、请假和调课原位置不作为去向；保留调课后的实际安排。事项的截止时间仍标为截止，不转成上课开始时间；没有钟点时保留节次，没有地点或匹配有歧义时明确提示。地名匹配仅使用明确建筑名／别名，含多个建筑的描述不会自动选一个位置。时间表模块关闭或不可用时，地图与电梯资料仍可用，日程区明确提示。

页面链接可带 `#campus-map?date=YYYY-MM-DD&event=事项ID` 或 `&location=教室原文`，只在本机定位。资料不缓存用户日程，离开页面中止请求、事件和样式。无持久用户数据、秘密、后台线程或付费服务。验证由 `checks/check_map.py` 与 `checks/check_locations.mjs` 覆盖。

## 试用版本

本轮保留在 `codex/campus-map` 分支，供本地试用后继续完善，不合入主分支。打开 `/#campus-map`，选择日期查看安排；点击日程或建筑查看详情，使用“电梯位置”切换资料图层。手机上点击安排会把对应地图位置带回可视区域。

合成检查覆盖具体楼号、相近楼号排除、多地点歧义、北京时间与截止语义、依赖停用、取消／请假／调课、账号切换、几何数据完整性、校门别名、道路坐标范围、固定屏幕字号和标签碰撞；完整检查仍使用仓库 `check.ps1` / `check.sh`。界面验收检查日期切换、课程定位、搜索、缩放、地图展开、校门地址、电梯来源链接、手机宽度和切页样式清理。
