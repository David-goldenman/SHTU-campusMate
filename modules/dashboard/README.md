# 校园总览

通过课程中心、作业管理和通知模块的公开 API 展示本学期统计、近期截止、来源状态、未读通知和课程入口。`GET /snapshot` 返回原课程快照及 stats、upcoming、notifications；`POST /sync` 委托课程中心更新已配置来源。作业和通知模块停用时显示可用数据，课程中心是必要依赖。统计及待办使用当前课程范围，未知截止不会生成日期。

运行项目 `check.sh` 验证当前学期统计、来源失败、已知截止和未读通知筛选。

## 未连接时的显示

所有来源尚未连接时，统计显示 `—` 并提供连接账号入口。重复的来源未连接提示合并为引导，独立错误和服务提示仍保留；来源可用后显示真实统计。总览继续使用原 `/snapshot` 与 `/sync`，近期作业、日程和通知字段保持原契约；外观由框架独立主题覆写。
