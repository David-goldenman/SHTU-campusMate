# 校园总览

通过课程中心、作业管理和通知模块的公开 API 展示本学期统计、近期截止、来源状态、未读通知和课程入口。`GET /snapshot` 返回原课程快照及 stats、upcoming、notifications；`POST /sync` 委托课程中心更新已配置来源。作业和通知模块停用时显示可用数据，课程中心是必要依赖。统计及待办使用当前课程范围，未知截止不会生成日期。

运行项目 `check.sh` 验证当前学期统计、来源失败、已知截止和未读通知筛选。

## 界面

`web/index.js` 使用现有快照渲染四项统计、近期截止、六个来源状态、重要通知和课程入口；`web/styles.css` 负责响应式布局。未连接来源时显示连接引导及 `—`，不把缺失数据当作真实的 0。来源状态保留文字，日期统一按上海时区展示。样式在退出、挂载错误和中止时清理。

本轮仅调整展示，不新增来源抓取、自动提醒或附件下载。Piazza 附件继续按已有数据和来源链接展示。

在本地服务启动后，运行 `node checks/check_web.mjs http://127.0.0.1:16666` 可检查实际空状态与隔离的合成数据界面；截图保存在 `.codex/tmp/ui-overview-*.png`。
