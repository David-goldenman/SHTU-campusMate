# 校园总览

通过课程中心、作业管理和通知模块的公开 API 展示本学期统计、近期截止、来源状态、未读通知和课程入口。`GET /snapshot` 返回原课程快照及 stats、upcoming、pending、notifications、agenda；pending 保留作业模块完整的待办列表，避免五条预览导致紧急数量漏计，旧 upcoming 字段保持兼容；`POST /sync` 委托课程中心更新已配置来源。作业和通知模块停用时显示可用数据，课程中心是必要依赖。统计及待办使用当前课程范围，未知截止不会生成日期。

首页默认展开“待办与截止”：24 小时内截止、已逾期仍可处理、待完成作业的数量可点击跳转到作业页相应筛选。最近四项未来截止与最近两项逾期分区显示，未提供截止时间的待办另有入口，历史逾期不会挤掉即将截止的事项。日期、时刻和剩余时间统一按北京时间显示；剩余时间在未操作控件时每分钟更新，不额外请求接口。今天／明天仅列有效安排，隐藏取消、请假、调课前位置及今天已结束的课程，截止事项在待办区展示。课程统计、来源与通知移入次级折叠区，来源错误仍保留；聊天可主动进入。

运行项目 `check.ps1` 或 `check.sh` 验证当前学期统计、来源失败、已知截止和未读通知筛选。

## 未连接时的显示

所有来源尚未连接时，统计显示 `—` 并提供连接账号入口。重复的来源未连接提示合并为引导，独立错误和服务提示仍保留；来源可用后显示真实统计。总览继续使用原 `/snapshot` 与 `/sync`，近期作业、日程和通知字段保持原契约；外观由框架独立主题覆写。


观星台／星夜手记主题的页面末尾可显示蓝白校园图片轮播，在设置 → 外观中独立开关。图片不附场景说明，默认 20 秒切换；可暂停、手动切换，并在离屏或减动态时停表。装饰使用共享 campus-moments 组件并随模块清理，不参与数据同步、课程布局或日程计算。
