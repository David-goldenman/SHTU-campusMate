# 虚拟教学社区

使用共享 IDS 的 `elrc` 目标。`GET /snapshot` 与 `POST /sync` 提供课程、章节资料和录播目录，课程和录播按平台课程标识与规范学期关联。课程资料保留完整路径；分页每页 50 条，检测重复页并限制 100 页，内容树限制 32 层与 10000 项。局部读取失败保留相应缓存并提示。

`GET /recording?course_id=录播课程ID&recording_id=录播ID` 返回课次及教师录播流；`GET /transcript?stream_id=流ID` 返回转写与学校摘要。应先读取录播课次再选流。转写时间从 100 纳秒单位转成秒，缺少有效时间时保留文字并说明；删除项跳过。已读取的正文更新到公开快照，供课程与 AI 模块使用。

模块拥有独立 Store，通过 `stop(context)` 结束同步。项目 `check.sh` 自动执行章节路径、语言元数据、转写时间与重复分页的合成检查。
