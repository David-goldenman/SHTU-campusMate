# Blackboard

使用共享 IDS 的 `blackboard` 目标。`GET /snapshot`、`POST /sync` 提供未完成课程、内容树、资料、作业、成绩与公告。课程代码与完成状态来自课程门户；学期优先按课程 REST 记录的 `termId` 读取学期名称，并以门户标签和课程名称兜底，避免因门户缺少学期而无法与教务课程合并。资料保留目录层级。内容树限制 32 层、10000 节点，并检测重复与循环；REST 分页采用公共限制。

作业保留 `true`、`false`、`null` 三种提交状态；读取 `/snapshot` 时把 `null` 统一输出为 `false`（没有提交记录即未提交），成绩页面的已提交、已评分或存在分数（包括 0 分）输出 `true`。作业截止时间取自成绩册列的 `grading.due`，与作业内容 ID 对应；没有成绩册列的作业保留空截止时间，不猜测日期。可用时间窗决定开放状态，未知值不会自动变成待办。单门课程或成绩读取失败会显示提示，其余课程继续读取，已有快照按课程保留。公告属于附加信息：页面不可读或条目元素缺失时静默跳过并保留上次公告，不计入提示，也不影响课程、作业与资料。

`GET /file?material_id=规范资料ID` 从当前账号快照确认文件，再读取 Blackboard 附件 API 或已确认的 `/bbcswebdav/` 路径；认证、目标校验、暂存和清理由公共服务处理。`stop(context)` 结束同步线程。项目 `check.sh` 自动执行本模块合成检查。
