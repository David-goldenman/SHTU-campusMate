# Blackboard

同步网络失败（包括局部课程失败）时 `/snapshot` 附带安全的 `network_failure` 标记。课程中心和来源页据此自动诊断；成功重试后清除，登录、权限和解析错误不触发网络诊断。

使用共享 IDS 的 `blackboard` 目标。`GET /snapshot`、`POST /sync` 提供未完成课程、内容树、资料、作业、成绩与公告。课程代码、学期和完成状态来自课程门户；资料保留目录层级。内容树限制 32 层、10000 节点，并检测重复与循环；REST 分页采用公共限制。

课程标题中的 `2026 秋`、`2026秋`、`2026年秋季` 和完整学年学期均可识别；旧缓存缺少学期时也按标题中的明确年份与季节补充。标题本身没有学期的课程保留空值，由课程中心结合其他来源的课程代码和学期依据关联。

已关联成绩列中的空提交状态表示尚未提交，统一输出 `submitted: false`；成绩页面显示已提交、已评分、接口状态为 `NeedsGrading` / `Graded` 或存在分数（包括 0 分）时输出 `true`。缺少成绩列不能视为未提交：同步会只读访问该作业的提交历史，以历史页中的尝试时间和提交内容确认已提交，上传表单或草稿确认尚未正式提交。不会上传文件、保存草稿或提交作业。无法核实时输出 `submitted: null`、`submission_evidence: unavailable` 并提示部分失败，此项不计入未提交和待办。

`submission_evidence` 标明 `gradebook`（成绩记录）、`submission_history`（作业历史）或 `unavailable`（未能核实）。旧缓存没有该字段的 `null` 在 `/snapshot` 读取时仍转换为 `false`；新同步中明确未能核实的状态保留为空。作业页、课程中心、待办筛选和 AI 上下文使用同一状态。开放状态由可用时间窗独立决定，尚未开放、关闭或开放状态未知的作业不会自动成为待办。单门课程、成绩或公告读取失败会显示提示，其余课程继续读取，已有快照按课程保留。

`GET /file?material_id=规范资料ID` 从当前账号快照确认文件，再读取 Blackboard 附件 API 或已确认的 `/bbcswebdav/` 路径；认证、目标校验、暂存和清理由公共服务处理。`stop(context)` 结束同步线程。项目 `check.sh` 自动执行本模块合成检查。
