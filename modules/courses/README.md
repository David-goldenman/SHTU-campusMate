# 课程中心

页面通过 `GET /view-state` 的 `{account_revision}` 核对最近一分钟的浏览器内存快照，可先展示同账号课程再后台更新。`/snapshot` 同时返回账号版本；写操作、账号变化与模块更新不会复用旧快照。未变化的资料保留当前 DOM，后台更新保留搜索条件、学期筛选与搜索框焦点。

手动课程分组按当前账号版本保存。`GET /groups` 返回 `{groups,account_revision}`，`PUT /groups` 必须携带同一 `account_revision`；旧账号表单或验证期间换号返回 409，缺少账号版本返回 422。页面打开关联表单时还会核对课程列表的账号。恢复自动关联只清除当前账号的分组。旧版无归属分组在模块首次初始化时一次性归属当时账号，保留原记录，切换账号或重载不会重新分配。

## 批量下载 Piazza 文件

在课程中心顶部点击“选择并记住资料总目录”，用 Edge 或 Chrome 选择一次可写总目录，当前账号的所有课程共用。目录按“总目录 / 学期 / 课程代码 · 课程名”组织，例如“课程资料 / 2026 年秋季 / EE130 · 电磁学”；学期未知时放入“学期待确认”。已存在和后续新增课程都会自动建立自己的文件夹，无需逐课选择；课程改名不另建文件夹，同名不同课程分别保存，学期修正时按新学期整理。

总目录旁的“自动拉取总开关”统一控制所有课程，首次选择目录时默认关闭；新课程自动跟随总设置。课程“资料”标签保留独立开关，可将某门课单独关闭，重新打开后恢复跟随总设置。总开关关闭时暂停所有自动拉取，但仍建立文件夹；“立即检查”可手动下载当前课程，页顶“检查全部课程”可手动检查所有课程。总开关开启后，进入课程中心、刷新页面或点击页顶“同步”会补齐未单独关闭的课程的 Piazza Resources 文件。切换总开关不会重置单课选择，刷新、更换总目录后也会保留。升级时保留旧的逐课选择：已有课程开启则总开关保持开启，原先单独关闭的课程保持关闭。来源同步期间等待目录更新；关闭总开关会停止自动任务，其他窗口排队或正在处理的任务在请求和写入前复核最新设置，手动检查不受影响。外部网页链接不当作文件下载，文件拉取范围仍为 Piazza Resources。

自动拉取作为常驻后台模块运行，不依赖打开课程中心或手动同步。总开关开启后默认每 15 分钟刷新 Piazza 目录并补齐新文件；总目录旁可选 5、15、30 分钟或 1 小时，按账号与总目录设置保存。工作台网页保持打开即可，切换页面或最小化后仍会检查；浏览器休眠可能延后定时器，完全关闭浏览器后暂停，下次打开继续。文件夹授权属于浏览器，服务端不持有目录句柄，因此仅保留本地服务进程不能继续写入所选文件夹。

前景页面和后台共用下载队列，多窗口通过 Web Locks 和持久检查时间避免重复刷新来源。后台先刷新 Piazza 的公开同步接口，等待目录完成后重新读取课程和下载清单；只下载新增、更新或丢失的文件。总开关关闭时不请求来源；单课关闭、本地修改保护仍然生效。目录权限失效时不弹授权框，在课程中心提示恢复；断网或来源失败后按所选间隔重试，无变化不反复通知。每 30 秒只检查本地设置，远端同步仍按用户选择的分钟间隔；停用、刷新模块或退出网页会清理计时器和请求。

总目录和每门课的下载清单保存在本浏览器 IndexedDB，按 Piazza 账号版本隔离，课程记录另按课程 ID 隔离；不向服务端传本机路径。页面显示统一总目录、课程相对路径、自动下载开关、检查间隔、最近后台检查、进度与失败原因。更换总目录对所有课程生效，未修改的应用文件在检查时迁移，用户修改的文件留在原处。忘记总目录会移除当前账号的目录关联与清单，磁盘文件保留，其他账号设置不变。浏览器重启后如需重新授权，点击“允许访问并继续”，无需重新选目录；换浏览器、清除站点数据或更换账号版本后须重新选择。

下载清单按资源 ID 记录版本与固定文件名，另保存大小、修改时间及本工具下载内容的摘要。同一份资料的新版本原位替换，文件丢失时补齐；未知的同名文件保留，新的不同资料仅在首次命名冲突时加稳定资源标识。同一资料不会因为版本更新产生编号副本。本地修改（包括清空文件）保留，暂停该资料的自动更新，页面显示原因；移走受保护文件后再点“立即检查”可重新下载最新版。下载等待及写入提交前重新检查本地修改，中断替换保留原文件。来源未提供内容更新时间变化时无法识别静默替换；无扩展名时按响应类型补齐。

旧版逐课设置若都使用同一总目录，会自动沿用；原来使用多个不同位置时，页顶提示选择统一总目录。IndexedDB 升级保留原课程清单、开关及已有句柄。平铺文件或旧版一层课程目录会在检查时整理到“学期 / 课程”中；同版本直接从本地迁移，无须重复下载。新文件及清单保存成功后才移除旧位置的未修改文件，只清理已经为空的旧课程文件夹。用户修改、旧版识别的自有文件或被多个课程同时认领的同名文件留在原目录，并暂停自动更新。未知文件不移动，不在资料目录留下清单或备份。

同浏览器多个窗口通过共享 Web Locks 队列串行完成目录分配、下载和记录保存；等待结束后重新读取来源快照与最新清单，避免跨课程覆盖或重复下载。停用模块或关闭工作台会取消排队，切换到其他工作台页面时后台继续；不支持 Web Locks 的浏览器停止批量写入并提示使用新版 Edge／Chrome。

点击“停止本次”、卸载模块或关闭工作台会取消后续下载，已保存文件和清单保留。仅离开课程中心不会停止常驻后台。中断的新文件清理，中断替换保留原文件；关闭浏览器后不继续下载。

实际保存新增或更新文件后，工作台弹出提醒，包含课程、成功数量、目标文件夹及未完成数量；同一次检查涉及多门课时合并提醒。全部跳过或全部失败不弹成功提醒。资料区保留最近一次成功拉取的时间、数量和文件名（最多展开 20 个），刷新检查无变化时保留该记录；记录随账号及课程的文件夹关联保存在本浏览器。离开页面后不弹出已卸载模块的迟到提醒。

通过 Piazza `GET /snapshot` 获取当前资料和 `account_revision`，将版本传给已有 `GET /file`；换号时终止该批次，避免同名课程跨账号混入。文件仍受 Piazza 的登录、30 MB 大小及目录范围检查，不新增服务端任意路径写入能力。检查：`python modules/courses/checks/check_downloads.py`（实际合成文件落盘、零请求跳过、清单恢复、增量与更新、本地修改保护、失败重试、取消与版本错误）。

## 课程名称与本学期标识

聚合名称优先采用来源中已有的中文名称，同语言按教务课表、教学社区、E 云课堂、Blackboard、Gradescope、Piazza 的顺序选择，不用 AI 翻译或覆盖原站记录。手动课程组标题始终优先。`title_source/title_source_id` 记录所选名称的来源，`aliases` 保留不同平台原名；页面与搜索同时支持原名和别名。

| 来源 | 适合提供的字段 | 名称使用方式 |
| --- | --- | --- |
| 教务课表（timetable） | 正式课程名、代码、本学期选课、上课时间 | 本学期课程主名称与学期依据 |
| 教学社区（elrc） | 中文课程名、学期、课次与录播 | 名称补充、历史课程与录播资料 |
| E 云课堂（ecourse） | 中文课程名、课程代码、历年学期 | 名称补充，尤其是教务当前课表未含的历史课程 |
| Blackboard | 教师设置的课程名、课程代码、教学资料与作业 | 保留班号／年份／英文等别名，资料仍按原课程 ID 关联 |
| Gradescope／Piazza | 作业与讨论平台的课程名称 | 保留英文别名，辅助搜索和群名匹配 |

只读 `GET /identities?current=true` 返回 `{items,account_revision,current_semester,unavailable}`；items 含 `id/title/title_source/title_source_id/aliases/code/term/current/course_ids`。默认只返回本学期，`current=false` 返回全部学期。此接口只读取学校来源的公开快照，不读取群消息、邮件或培养方案，供群消息匹配使用，避免课程聚合与群消息互相调用。课程身份仍按课程代码、学期及已有手动分组确定，名称选择不改变课程 ID。

课程卡片和详情按开课院系显示颜色与文字标签：创管紫、创艺橙红、生命棕黄、物质绿、数学所深蓝、信息浅蓝，体育与书院红。院系优先取课程来源明确字段，缺失时按唯一课程代码匹配教务培养方案；冲突或未知保留中性色。`PE/CLPE` 课程代码标记体育课并显示 Font Awesome 跑步图标。

`GET /appearance` 返回 `{courses:[{id,course_ids,code,term,department,department_source,appearance}],palette}`，`appearance` 包含 `key/label/accent/tint/ink` 和可选 `icon`。时间表通过该公开接口匹配课程；课程模块不调用时间表的 `/schedule`，不会形成聚合循环。缺少教务模块仍可使用来源院系。所有院系判断位于课程模块；共享 UI 仅提供校验六位十六进制颜色的 `applyAccent(element, appearance)`。

E 云课堂（`ecourse`）通过公开快照接入课程、课件说明、公告和作业；统一同步会触发其只读刷新。原站提供的学期、课程代码及开课院系保留在课程来源记录中，附件通过原站课程栏目查看。来源停用按现有协议降级，首页助手通过 `/context` 使用同一份资料。

作业分类与作业管理共用提交状态标签，区分草稿、待评分、已评分、豁免和待核实；pending 筛选排除豁免与未知状态。`POST /context` 同时保留 `submission_status/submission_evidence/submission_reason/checked_at/submitted_at/submission_stale/exempt/due_at_evidence`，供 AI 与通知使用来源证据，而不是只看一个布尔值。

`GET /snapshot` 的 `network_failures` 转发已启用来源的网络故障标记。页面自动检测并在同步提示旁给出原因和处理建议，无需进入设置；仅来源明确的网络错误触发，成功重试后清除。

界面以本学期的课程为入口，每门课程汇总已连接平台的可用内容，提供资料、作业、公告、讨论、录播、上课安排及平台成绩条目分类与原站链接。页面使用 `navigation.layout:primary`，平台来源保持 API 与同步能力。可查看其他学期、搜索课程，并用可勾选列表手动关联不同平台的同一课程。

课程列表直接展示录播状态与已收录条数、待办及资料数量，支持「有录播／暂无录播／待确认」筛选。录播状态依据当前快照中按来源课程 ID 关联的 `lessons`，不把教学社区平台入口当作录播证据；只有来源读取成功、无该来源问题、无未关联录播且课程已关联教学社区时，零条记录才显示「暂无录播」。未同步、读取失败、缓存或课程尚未关联时显示「录播待确认」，已有录播仍保持可见。数量代表快照记录条数，不推断实际课时数。详情始终保留录播标签及空状态，有记录时提供直接进入录播列表和原站的入口。

录播默认通过主要按钮「在官方观看」或录播标题在新标签页打开原站。教学社区录播保留次要按钮「内嵌播放」，在课程页内选择课次和画面，支持原生进度拖动、全屏与 0.75–2 倍速。切换教师、全景或屏幕画面保留当前进度和播放/暂停状态；切换课次从头开始。关闭播放器或离开课程模块会停止视频、取消请求并清理样式。播放器脚本与样式仅在用户选择内嵌播放后加载，使用 ELRC 的公开播放接口。

搜索、录播筛选、课程切换和内容标签使用一次 `/snapshot` 的公开数据在本页完成，不反复请求聚合 `/course`；关联课程时才读取 `/groups`。课程待办数量与公开 `pending` 筛选保持一致：包含 Blackboard、Gradescope 和 E 云课堂中明确开放、未提交或草稿的作业，排除豁免、待核实和已提交状态。新增状态检查在 `checks/check_summary.py`，由完整检查入口自动运行。

浏览器回归使用 `node modules/courses/checks/check_web.mjs <本机地址>`，以合成数据检查录播证据与筛选、跨平台待办、课程关联、键盘切换、四种主题的电脑／手机布局和卸载清理。截图保存在 `.codex/tmp/courses-ui/`。公共工作区联动检查沿用 `node checks/check_campus_workspace.mjs <本机地址>`。

自动关联先规范课程代码中的空格、横线与大小写，再按代码和学期合并。缺少代码时，只在相同规范名称和学期唯一对应一个已知课程代码时关联；有多个候选保留独立，交由用户手动选择。

Piazza 的 Resources 文件与链接通过其公开快照进入“资料”，讨论帖继续放在“讨论”。文件可在浏览器查看或下载，使用 Piazza 模块的本机文件接口复用已保存登录态；目录中的资源更新时间参与助手读取版本校验，PDF 正文由学习助手按需提取。

Blackboard 活跃课程缺少学期时，只有相同规范课程代码在已有来源中唯一对应本学期，且教务课表或 ELRC 提供该学期证据，才参与本学期自动关联。已明确的历史学期、多个学期候选、无匹配代码、未知/已结束状态均不据此推断；不能单凭 `active` 认定本学期。手动分组优先。聚合课程的 `term_matches` 保留被匹配课程、学期与证据来源 ID，`sources` 中的原始记录保持原样。

通过 `context.api` 读取六个来源的公开快照，维护自身课程关联设置。代码与规范学期一致时自动合并；缺失代码的唯一名称匹配见上文，其他课程保持独立。`GET /snapshot` 返回聚合课程、八类内容、来源状态及读取范围。本学期依次采用教务当前学期、ELRC 学校当前学期；二者都未提供时才按上海日期估计。`POST /sync` 请求已配置账号的来源同步。

`GET /catalog/{collection}` 支持 course_id、current、pending、source、q、offset、limit，limit 最大 500。pending 只适用于作业，要求来源为 Gradescope、Blackboard 或 E 云课堂、明确开放且明确未提交，并排除豁免与待核实状态。`GET /course?course_id=聚合ID` 返回各平台课程、资料、讨论、录播、作业和折叠课表。

`GET/PUT /groups` 读取或完整保存 `{groups:[{id,title,course_ids}]}`；每组 2–20 个已知来源课程，每门课仅属于一个手动组，空数组恢复自动关联。模块不读取其他模块数据库。项目 `check.sh` 执行来源不可用、学期关联、三态待办及手动关联检查。

`POST /context` 接收 `{course_id?:string, context_ids?:string[]}`，返回 `{items,courses,text,context,account_revision,revision}`。这是助手和通知模块使用的公开资料选择接口：默认选择本学期课程及邮件；指定课程时只取该课程资料并排除邮件；显式空 context_ids 得到空资料，未提供则按课程范围选择。每条正文最多 1800 字、最多 400 条、序列化上下文最多 85000 字符；截断计数放在 context 中。items 带 source_revision，revision 结合当前账号及所选资料版本；调用方完成异步 AI 操作后仍需核对 account_revision。未知课程返回 404，失效选择返回 422，读取过程中切换账号返回 409。来源模块缺失按 snapshot 的 issues 降级；本接口只读缓存，不触发同步或 AI。

可选群消息模块通过公开 `/snapshot` 补充已确认的课程公告，缺失或停用不影响六个学校来源。群原文不进入课程聚合；同步按钮不触发聊天采集。

本地无需提交选择通过 assignments GET /handling 读取，不访问其他模块 Store。快照及 /context 保留 handling/reminder_suppressed，课程待办数与 pending 筛选排除被标记项目，作业列表保留原站状态及本地说明。该接口不再读取 courses，因此不会形成聚合递归；不可用时在 issues 说明。
