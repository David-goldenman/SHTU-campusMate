# 画面节奏与运动

当前成片 346.5 秒，1920×1080、60 fps。`src/film.json` 保存章节时长、字幕与 `transitionSeconds`；`src/operations.json` 保存每一步的起始时间及运动时长。调整后同步更新配乐并录制相关片段，大纲和完整脚本由 `scripts/check.mjs` 生成。

章节过渡占前段末尾 1.2 秒及后段开头 1.2 秒：先以平滑加减速收起画面，霜蓝线条沿曲线运动，Nord 底色上的标题提示下一功能，随后展开下一界面。两段共用同一条线和标题位置，在场景边界连续衔接。文字与线条分别位于中部和下部。产品操作在入场后开始；界面内部切页以 0.85 秒淡入和轻微位移呈现。

每段最后一个动作及取景运动结束后，先保留约 3 秒以上完整可读时间，再进入出场。邮件原文、课程教室、四周截止、录播、群消息依据和确认回执分开停留；AI 回答完成后继续显示结果，再打开引用或切换时间表。三个个性主题各展示 5.5 秒，内部擦拭为 1 秒。日程局部视图在实际截图完成后展开，手机地图阶段跟随实际导航时间，路线绘制跟随目的地选择。

桌面鼠标全程保持可见。点击、关闭、选择和输入之前，先用 1 秒沿二次贝塞尔曲线移动，再停留约 0.05 秒执行操作。位置在 60 fps 时间轴上逐帧计算，首尾平滑加减速；滚动、工具进度和流式回答期间保留鼠标当前位置。打开模态窗口时，鼠标进入窗口所在显示层；关闭时保持视口坐标回到页面。手机片段按触屏操作展示。

录制时检查相邻帧的鼠标位移，单帧上限 48 CSS 像素；执行操作时与目标的误差上限为 5 CSS 像素。每段记录最大实际位移与误差，保存在 `production/captures.json`。检查器同时核对移动目标与操作目标、动作顺序、片尾阅读时间、截图取景及素材帧数。

`scripts/review.mjs` 从实际操作时间提取输入、流式回答、完成结果、重点镜头、引用、回执与设置标签的检查时刻。`npm run stills` 另生成邮件、AI 日程、主题章节边界的连续帧。成片抽帧与完整解码结果保存在 `production/validation.md`。
