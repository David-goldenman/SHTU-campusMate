## 视觉与制作

Nord 配色来自项目默认主题。[Google Material Motion](https://m3.material.io/styles/motion/overview) 用于空间衔接与节奏参考。[Remotion 官方文档](https://www.remotion.dev/docs/) 是帧编排及导出的依据；[OffthreadVideo](https://www.remotion.dev/docs/offthreadvideo) 从录制片段读取对应帧。流程参考 [ai-promo-video-maker](https://github.com/liyupi/ai-promo-video-maker) 的脚本、真实界面取材和分镜保存方式。

方舟风格参考用户先前提供的 [明日方舟官网](https://ak.hypergryph.com/#index)、[腾讯游戏学堂分析](https://gameinstitute.qq.com/article/10027)、[PRTS Design](https://mooncellwiki.github.io/prts-design/)、[PRTS 主题一览](https://prts.wiki/w/%E7%95%8C%E9%9D%A2%E4%B8%BB%E9%A2%98%E4%B8%80%E8%A7%88)。PRTS 角色与场景使用项目现有主题资产，权利属于相应权利人，链接见主题 README。观星台和星夜手记同样展示项目实际主题及其已有插图。

配乐为用户指定的本地 OGG，用于本次黑客松现场演示。名称和署名字段由 `src/film.json` 管理。

## 最新功能的演示素材

校园地图直接使用项目 `modules/campus-map/data/` 中的学校官方建筑数据、OpenStreetMap 底图与步行路网，保留画面中的 OSM 署名。演示从图书馆规划至教学中心，路线由实际前端计算；蓝色线条按该路线几何绘制。地点、近似距离与步行时间使用产品实际结果，开放情况以现场为准。

群消息运行 `modules/group-messages/web/` 的真实页面。课程群名称、助教身份与同步状态为演示数据，文本沿用已核对的 CS100 HW2 标题与 10 月 22 日 23:59 截止。提取、原文展开、确认准备待办和撤销均由实际按钮触发，业务回复在隔离浏览器中重放；没有读取个人聊天。微信与 QQ 的接入范围以当前模块 README 为准。

微信与 QQ 来源聊天窗使用 React/CSS 还原。微信参考[微软商店公开客户端展示图](https://store-images.s-microsoft.com/image/apps.43950.13510798887572783.84ab0bba-b9cd-44c0-b36c-49108daf9073.9dbe7e49-5635-4a9f-a425-91fa935c7d95?q=100&w=1360)，QQ 参考[腾讯官网的桌面客户端演示](https://static-res.qq.com/static-res/imqq/video/mod-c.mp4)。保留侧栏、会话列表、群标题、发送者、时间分隔、输入区和各自的气泡样式。所有群名、成员、头像与对话重新编写为课程场景；事实锚点是已核对的 CS100 两部分作业与信号与系统 HW2 截止。数据保存在 `group-chats.json`，同一条助教消息用于后续工作台原文引用。视频标注「聊天界面还原 · 演示消息」，用于表现课程群信息进入工作台的使用过程。

近四周网格、苹果日历导出入口、课程录播状态与登录界面使用 main 的实际实现。日历导出按当前时间表模块提供 `.ics` 文件，具体范围见 `modules/timetable/README.md`；视频展示真实入口，苹果设备导入另行实测。录播演示只使用来源快照已收录的条目，不把平台入口视为录播。IMAP 表单显示虚构账号和已配置状态，密码输入保持空白；未进行真实邮件登录。

手机素材是同一真实前端在 430×860 CSS 像素、2 倍设备像素比下运行的响应式视口，展示逐日安排和校园地图。制作名单由用户直接提供，按 GitHub 名称字母顺序呈现。
