# campusMate · 制作说明

面向中文黑客松评审与现场观众，以分散的信息为起点，展示 campusMate 如何把课程、作业、邮件、课程群与校园行程连在一起，再介绍 AI Agent 协作。1920×1080、60 fps，当前时间轴 346.5 秒。中文标题、说明与真实界面承担叙事，背景音乐使用指定 OGG。

默认 Nord 为主视觉，使用极夜蓝、雪白与霜蓝。每次章节切换先保留结果，再由线条收起界面、显示下一功能标题，最后展开新界面；完整过渡为 2.4 秒。界面内按实际操作进行输入、点击、滚动、筛选与流式回答，每项鼠标操作先沿曲线移动到目标。镜头从完整视口进入明确的内容区域，推近、高亮并稳定阅读，随后回到全景；地图路线按真实路线几何绘制。标题与说明位于界面之外。桌面以 2760×1350 录制，放入 1840×900 的演示窗口，为局部放大保留像素余量。

故事顺序为：信息分散 → 首页待办 → 邮件分类与偏好 → 课表、校历及近四周截止 → 当天地点与步行路线 → 课程中心、录播与跨平台作业 → 微信／QQ 课程群消息整理 → 学业信息 → AI 添加日程、后台通知、课件复习与选课 → 手机逐日安排与地图 → 学校统一登录、邮箱 IMAP、多模型及模块组合 → PRTS、观星台、星夜手记 → 制作团队。

演示日期为 2026 年 10 月 19 日。真实群发通知、公开活动标题、作业名称、截止及资料标题保留出处；学生背景、在修组合、完成状态、个人日程和考试为演示状态。微信、QQ 来源窗口参考真实客户端，使用代码还原；群名、人物和对话为虚构示例，沿用真实 CS100 HW2、信号与系统 HW2 的名称与截止。工作台内的群消息页面使用真实前端，确认与撤销只操作隔离浏览器内存。AI 日程回答取自已保存的脱敏对话，复习与选课回复为已核对素材的示例。手机片段运行同一真实前端的 430×860 CSS 像素响应式视口，不表示云端同步或独立原生应用。

结尾署名为「AAA罗德岛工程部 制作」，按 GitHub 名称字母顺序展示 @David-goldenman 钦佳麒、@flowing-wind 杨涵、@Lucas-reconscope 张天祺、@wEn-EE 文玉涛，并保留项目仓库地址。
