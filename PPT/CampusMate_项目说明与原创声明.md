# CampusMate 项目说明与原创声明

AAA罗德岛工程部    2026 年 10 月 18 日

CampusMate 是面向大学生日常学习的本地 AI 工作台。我们把分散在教务、教学平台、邮箱和课程讨论区的信息整理到同一个界面，让学生查看本周课程与作业、追踪重要通知，并在需要时根据课程原文获得学习建议。本文介绍项目、团队成员、主要功能及原创范围，供黑客松评审使用。

## 项目简介

一个学习任务往往跨越多个入口：课表在教务系统，课件在 Blackboard，作业在 Gradescope，补充说明在 Piazza 或邮箱。学生需要反复切换平台，自己核对截止日期、地点与原文。CampusMate 以课程和时间安排为主线，把这些资料连接起来，减少重复查找与手工整理。

项目以 Windows 本地网页为主要交付形态，连接用户本人账号后读取已有学习资料，提供课程中心、作业管理、邮件分类、时间表和学习助手。用户可先浏览本地已有内容，来源同步在后台继续；AI 按具体问题选择所需资料，通过工具获取信息、执行获准的本地操作，并展示来源与操作结果。

## 基本使用流程

在设置中连接学校及课程平台账号，选择需要启用的模块；同步后，从首页查看待办和今日安排，从课程中心进入资料与作业。需要规划、复习或调整本地安排时，可向学习助手提出问题，查看原文依据与执行回执后核对结果。

## 功能说明

### 课程与作业汇总

按同一门课整合 Blackboard、Gradescope、Piazza 及可用录播内容，汇总课程资料、作业截止和来源入口。作业区分待完成、已提交与状态未知，支持筛选、进度管理及截止提醒；来源没有给出明确结果时保留未知状态。

### 结合个人需求整理邮件

邮件分类结合当前课程、年级、形策与心理活动完成情况、兴趣及用户偏好，保留分类理由与原文。用户可手动调整分类，已编辑结果优先保留；提供日总结和周总结。目前读取范围为最近最多 100 封已同步收件箱邮件。

### 时间表与可核对的安排操作

周视图整合课程、截止事项、考试和个人安排，近四周网格集中展示作业。支持新增或修改本地安排，以及请假、停课、调课等本地覆盖记录；操作返回变更前后内容、影响范围和冲突检查结果。活动建议经用户明确参加确认后加入时间表。

提供标准 .ics 日历文件，导出近四周的课程与作业截止，包含课程地点、稳定标识和作业提醒。支持文件导入的日历应用可读取该格式；不同手机的实际导入与提醒效果仍需实机确认。

### 带原文依据的学习助手

通过 DeepSeek Harness 原生插件按需查询课程、作业、邮件与时间表。复习问题可定位 PDF 或 PPTX 的具体页码，回答附来源和原文片段；扫描页与图片可使用已配置的视觉模型或本地 OCR。识别结果与文件原文分别标注，资料不足时说明具体缺口。

### 结合学业信息讨论选课

结合已有修读记录、培养方案、课程目录及教学大纲讨论后续学习方向与课程负担。建议依赖已取得的资料，未来学期的开课、时间冲突及正式选课结果以学校当期公布信息为准。

### 后台通知与持续同步

来源同步在后端执行，切页后继续，返回页面可恢复进度。程序运行期间按缓存时效检查已连接来源；后台助手在资料变化后提出新的可行动提醒，尊重用户偏好、参加选择和手动编辑。

### 主题和延伸体验

提供 Default Nord、观星台、星夜手记与 PRTS 学习终端，保持同一套业务 API，并支持窄屏网页。校园地图提供建筑定位和室外步行试用；群消息支持本人微信本机只读接入与 QQ 本机 OneBot 接口，提取结果保留原文、确认与撤销入口。

## 原创声明

我们声明，CampusMate 的项目选题、校园业务功能设计、资料整理规则及跨模块交互流程由团队自主完成。在工程功能设计方面，外部参考为 DeepSeek Harness 的 Agent 运行时与原生插件机制；其余项目功能由团队结合校园实际使用需求设计。

项目集成 DeepSeek Harness 官方运行时和 SDK，并使用通用开源库、身份认证组件与公开协议。上述组件的原始实现及权利归属保留给原作者，具体用途、版本和许可在配套技术与第三方资源说明中列明。团队的原创成果主要体现在校园来源适配、课程与作业聚合、个性化邮件规则、带引用的学习工作流、本地安排操作及模块协作实现。

UI 主题设计参考了游戏《明日方舟》的视觉语言和 Hermes Agent 官方网站的设计表达。其中，《明日方舟》参考用于 PRTS 主题的终端布局与工业面板；Hermes Agent 官网参考用于蓝白艺术主题的古典图像与版式表达。Hermes 仅作为官网视觉设计参考。相关主题的代码与校园业务适配由团队完成。

PRTS 主题中实际使用的角色立绘、场景图与游戏对白属于原权利人。项目自行制作及生成式 AI 辅助制作的图像按素材记录列示；我们保留第三方来源、署名与相应许可，不将其列为团队独立创作的原始素材。本声明不改变第三方资源的许可证和权利归属。

## 当前完成情况

当前集成 19 个模块，已形成从账号连接、资料同步、课程与作业浏览，到带引用问答和本地时间安排的完整使用流程。仓库验收记录覆盖教务、Blackboard、Gradescope、Coremail、ELRC 与 Piazza 的真实登录或基础同步，以及学习助手的真实资料问答；不同来源的验证范围以对应记录为准。

地图的道路开放、入口及无障碍条件仍需现场核验；微信群与 QQ 接入在主项目中的真实课程群增量验收仍需补充。移动端当前为响应式网页，桌面壳和更大范围试用属于后续工作。项目现阶段以功能验证和小范围使用为主，尚无对外报告的用户规模或节省时间统计。
