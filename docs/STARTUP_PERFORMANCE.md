# 启动与首页读取性能

2026-10-22 本地优化，针对首页完整数据包、重复聚合、静态资源重复传输及启动探测等待。保留原接口、来源状态、未知待办、账号隔离与模块生命周期，不引入额外运行服务或跨请求业务缓存。

## 首页摘要

`GET /api/v1/modules/dashboard/summary` 保留统计、全部待办的必要字段、近期预览、今明日日程、通知引用、来源覆盖、更新时间、网络错误与来源提示。`data` 只含 `metadata/issues`，不再把完整课件、录播、邮件和课程记录发给首页。`/snapshot` 保留完整响应，其他调用方继续使用。

首页调用 `sourcePanel(..., {snapshotPath:'/summary'})`；其他来源面板默认行为不变。所有主题仍通过同一业务视图展示摘要，完整待办集合用于计算紧急数量，不能以五条预览代替完整集合。

## 请求内读取复用

框架为一次模块 GET 请求建立读取批次。业务通过 `context.api(..., reuse_key=账号或资料版本)` 明确声明可复用的读取，默认不复用。同一批次的并发请求共享实际请求，成功 HTTP 结果在批次内保留；错误响应和异常允许重试。模块实例、路径、版本均参与识别。每次仍检查模块是否可用，实际请求仍参与活动计数，取消调用者不提前释放尚在执行的模块资源。

`read_once(context, key, revision, load)` 供同一模块多个入口复用只读计算，完成前后核对版本，每个调用者获得独立数据副本。计算由领头调用内联执行，不创建脱离模块生命周期的后台任务。批次结束立即关闭并清空，继承旧上下文的后续任务不能继续使用缓存。POST/PUT 等调用不参与复用，并清空所属读取批次已有结果。

来源快照原有的过期检测与去重刷新仍在首次实际读取时执行；只在当前请求内复用该次读取，不延长来源缓存有效期。通知 `/snapshot` 会执行作业、邮件与过期核对，未标记为可复用 HTTP 读取。同账号同时进行的通知核对共享正在执行的任务，每个调用者最终重新读取当前本地通知选择；任务结束即移除。后续请求照常重新核对。

通知浮窗改用 `campus-agent/widget`，只传状态、通知标识/版本、预览和引用来源类型；`/status` 保留原响应。初次显示不重复弹出旧通知、手动已读及账号变化的处理保持原逻辑。

## 静态资源与设置页

公共 `/assets` 资源使用 `private, no-cache`，由 ETag/Last-Modified 校验更新，未变化可返回 304。API、根页面和错误响应继续 `no-store`。带内容版本的模块资源保留原有长期缓存。选择条件缓存便于开发更新，避免额外引入资源打包系统。

侧栏、favicon 与触屏图标分别使用 96、48、180 像素的 PNG。原始品牌图保留；`scripts/build_icons.py` 从原图生成显示资源，不在应用启动时处理图片。主题偏好更新时，只有资源地址确实改变才重新设置图片地址。设置页脚本及专属依赖在进入设置页时加载，保留超时、切页中止和主题默认视图入口。

## 启动探测

启动循环先做短 TCP 探测，端口尚未监听时无需耗尽完整 HTTP 超时。能连接后仍执行完整 bootstrap 就绪检查，不能仅凭端口打开就宣布成功。已有实例身份校验、端口占用检查、总启动超时和安全停止流程保持原有行为。

## 验证

回归包含请求内并发/隔离/取消/错误/换号/写后失效，模块停用恢复，完整与摘要接口一致性，通知核对与原站状态保留，静态资源 304 及内容更新，以及已有四主题和设置交互。性能使用同一份合成数据对照，首次样本预热，至少十个计时样本；新后端启动与浏览器首页显示分别计时。

2026-10-21 的初始真实实例测量、2026-10-22 本轮对照脚本和详细结果保存在开发目录 `.codex/startup-audit-20261021/` 与 `.codex/startup-optimization-20261022/`。性能测试不调用外部 AI，合成对照不复制真实账号资料。

## 本轮对照结果

2026-10-22，同机、相同合成数据与浏览器，先预热一次，再取十次测量；源码基线包含本轮之前已有的本地改动。浏览器首页计时从导航开始到主要内容可见，后台计时包含启动入口执行至完整就绪检查通过，二者分别测量。

| 指标 | 优化前 | 优化后 |
| --- | ---: | ---: |
| 首页显示中位数 / P90 | 1.390 / 1.416 秒 | 0.862 / 0.872 秒 |
| 首页响应正文 | 1,379,149 字节 | 24,632 字节 |
| 再次进入首页的资源传输中位数 | 7,425,530.5 字节 | 53,357.5 字节 |
| 首页与浮窗并发读取中位数 | 634 毫秒 | 265 毫秒 |
| 后台热启动中位数 / P90 | 4.154 / 4.171 秒 | 3.687 / 3.771 秒 |

首页达到中位数低于 1.5 秒、P90 低于 2 秒的本轮目标；后台热启动仍略高于争取达到的 3.5 秒。全新目录首次启动为 6.800 / 6.899 秒，未体现加速，不纳入热启动统计。首次浏览器访问为 1.573 / 1.037 秒，仅各一个样本，不能据此推断稳定的冷启动分位数。

合成场景包含 8 门课程、90 条作业、200 份资料、120 条录播、100 封邮件和 40 条帖子，两版首页均显示 8 门课程、16 项待办、200 份资料、8 个就绪来源。上述数字用于比较本轮改动，不与前一天真实账号数据的测量直接拼接；实际耗时受资料量、后台同步及电脑负载影响。

完整检查通过：79 项 Python 检查、13 项 JavaScript 检查、Windows 启动器检查和 106 项 JavaScript 语法检查；四主题多视口、校园工作区、学业助手与设置页加载验证通过。测试服务已退出，日常本地实例已更新，19 个模块就绪。
