## 可重复的回归检查

执行 `bash check.sh`。检查使用合成账号和模拟 HTTP，私有数据不会成为测试夹具。

- 同账号重新导入与续期保留 `account_revision`；确认换账号才切换缓存归属。未知旧会话不自动迁移给新账号。
- 分页读取中途登录失效，仅重新登录一次并重读；二次验证不循环尝试。网络和课程权限错误保留独立含义。
- ELRC/Piazza 原有 API 与聚合 API 在切换账号后不返回旧资料；切回原账号仍可读取其保留的缓存。同步前后检测账号版本，过期请求不回写当前账号。
- 设备认证失败也持久化签名计数器，多个 Vault 实例不会覆盖其他实例的更新。注册结果未知时保留加密私钥，恢复确认后才启用。
- 同步局部失败保留上次有效数据；重启后四个已验证来源的快照仍可读取。
