# 蓝白艺术主题实现

在设置 → 外观选择观星台或星夜手记，也可以使用侧栏底部的外观入口。

## 视觉与简约

观星台以钴蓝侧栏、古典雕塑和天球的雕版图像组织视觉；星夜手记用浅色侧栏、天文图册和单蓝线条。古典器物代表观察与求知，几何走线联系现代工具；主要文字与控件使用清楚的系统字体，首页标题局部使用系统衬线字。

主图约 220px 高，移动端缩到 182px，短屏隐藏。新版首页保留待办首屏，进入学习助手的空白对话后显示主图；输入后和有消息时收起，不改变聊天节点、流式请求或已有会话。正文、邮件、课表、列表和表单保持浅底深字。角色插画放在外观设置，每个主题分别选择男版、女版或隐藏。

## 代码位置

- web/themes/appearance.js：偏好校验、应用、保存、跨标签页同步和外观设置。存储键为 campus.appearance.v1。
- web/themes/observatory.css、star-notes.css：各自配色和主图。
- web/themes/art-workspace.css：公共控件、侧栏与外观设置样式。
- web/themes/assets/：两张新主图、四张已确认的人物插画、标记和提示词索引。
- modules/academic-assistant/web/welcome.js、welcome.css：首页艺术区域和响应式布局。
- web/settings.js：新增外观标签，保留原有设置分组。
- web/index.html：主题加载、侧栏标记和外观快捷入口。

切换主题只修改根属性与样式，不重挂聊天、不刷新模块。绑定到设置页的监听器沿用 context.signal，切页自动清理。首页艺术样式由模块自己的 useStyle 管理。

## 资产与生成

主图使用内置 image_gen 制作，风格明确为铜版雕刻与单蓝凸版印刷的现代重释，并非复制 Hermes 的成套素材。准确生成提示词保存在 web/themes/assets/art-prompts.json。人物沿用用户已确认的 A 组科幻动画男女版本、B 组简练漫画男女版本；原始 PNG 保存在仓库外原目录，网页仅做 WebP 编码优化。

图片内容和正文分别呈现，颗粒只在插画中。页面不加载外部字体、图像 CDN 或额外模型服务。

## 校园图片轮播

从用户提供的校园照片中选取五张，经内置 image_gen 做蓝白网点风格化。页面只显示图片和必要的轮播控件，不显示场景名称、地点推断、配文或编号。原始照片不改动；资产来源文件名和准确提示词见 web/themes/assets/campus-prompts.json，处理原稿存于仓库外 UI设计探索/20261018-校园蓝白轮播。

首页与时间表各自在页面末尾挂载一处组件。设置 → 外观可分别开关位置、自动轮播，并选择 10／20／30／60 秒间隔，默认 20 秒。图片进入可见区域才请求首图并启动；离屏、后台标签页、鼠标停留、键盘焦点或减少动态效果都会停表。手动前后切换后保持暂停，可用播放按钮恢复。控制按钮支持键盘、可见焦点及 44px 触控尺寸，触屏始终显示；桌面鼠标悬停或键盘焦点进入时显示。

五张 WebP 共约 716KiB，不预加载全组；固定容器尺寸，双图层淡入，不覆盖课程格、表单或正文。加载失败保持当前图片，并有界尝试其余图片；清理移除计时器、观察器、全局监听器，并拒绝迟到的图片回调。偏好仍使用 campus.appearance.v1，新增 rotation.autoplay 与 rotation.seconds；原有主题和每页开关兼容保留。

实现位于 web/themes/campus-moments.js、campus-moments.css；两个业务模块只在自己的页面末尾调用。checks/check_campus_moments.mjs 用合成 DOM 和可控时间验证轮播、暂停、可见性、减动态、错误跳过及卸载，不接触真实账号。
