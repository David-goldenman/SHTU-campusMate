# 蓝白艺术主题实现

在设置 → 外观选择观星台或星夜手记，也可以使用侧栏底部的外观入口。

## 视觉与简约

观星台作为深蓝夜间主题，以钴蓝侧栏、暗蓝阅读区、古典雕塑和天球的雕版图像组织视觉；星夜手记作为纸白日间主题，保留浅色侧栏、天文图册和单蓝线条。古典器物代表观察与求知，几何走线联系现代工具；主要文字与控件使用清楚的系统字体，首页标题局部使用系统衬线字。

首页先显示学习助手的双语文案与主图，再显示待办与校园总览。桌面主图约 252px，手机按内容自然增高；进入空白对话仍保留欢迎图，输入后或已有消息时收起。短横屏的对话视图隐藏主图，为输入区留出空间，不改变流式请求与已有会话。观星台正文、邮件、课表、列表和表单使用深蓝底与浅字，星夜手记保持纸白底与深字；两者都保留清楚的语义颜色和焦点。角色插画放在外观设置，每个主题分别选择男版、女版或隐藏。

## 代码位置

- web/themes/appearance.js：偏好校验、应用、保存、跨标签页同步和外观设置。存储键为 campus.appearance.v1。
- web/themes/observatory.css、star-notes.css：各自配色和主图。
- web/themes/art-workspace.css：艺术主题的公共控件与侧栏；appearance.css 提供外观设置样式。
- web/themes/assets/：两张新主图、四张已确认的人物插画、标记和提示词索引。
- web/themes/art.js、art-welcome.css：首页艺术展示区域和响应式布局，由主题清单加载。
- web/settings.js：新增外观标签，保留原有设置分组。
- web/index.html：主题加载、侧栏标记和外观快捷入口。

主题按 [主题契约 v1](UI_THEME.md) 在各自的 theme.json 声明样式和展示入口。切换后保存选择并重新打开当前页面，统一恢复对应界面与模块。绑定到设置页的监听器沿用 context.signal，切页自动清理；人物偏好继续按主题保留。

## 资产与生成

主图使用内置 image_gen 制作，风格明确为铜版雕刻与单蓝凸版印刷的现代重释，并非复制 Hermes 的成套素材。准确生成提示词保存在 web/themes/assets/art-prompts.json。人物沿用用户已确认的 A 组科幻动画男女版本、B 组简练漫画男女版本；原始 PNG 保存在仓库外原目录，网页仅做 WebP 编码优化。

图片内容和正文分别呈现，颗粒只在插画中。页面不加载外部字体、图像 CDN 或额外模型服务。

## 验证

完整检查使用 check.ps1；偏好检查覆盖 Default 选择、每主题人物记忆、只读副本、跨标签同步、主题视图、专属偏好及暂时缺失的主题。浏览器检查覆盖三个主题的选择和重新打开。

实际浏览器检查涵盖桌面、375px 手机、极窄窗口及横屏；验证输入后主图收起、跨标签切主题保留草稿、人物隐藏、键盘方向键、可见焦点、偏好刷新恢复与减少动效。未发送真实聊天或调用付费模型。主要正文保持 16px，辅助文字 12–14px；星夜手记抽查的正常文字对比度为 5.49:1–12.19:1，超过 4.5:1。观星台正文、辅助文字与侧栏同样核对；作业绿色评分与红色迟交文字采用更深的语义颜色，时间表迟交字样提升到 12px。

截图在本项目 .codex/screenshots/art-themes/；检查日志为 .codex/art-themes-final-checks-20261017.log。主题通过独立功能分支与 PR 共享，个人启动器不包含在主题变更中。


## 校园图片轮播

从用户提供的校园照片中选取五张，经内置 image_gen 做蓝白网点风格化。页面只显示图片和必要的轮播控件，不显示场景名称、地点推断、配文或编号。原始照片不改动；资产来源文件名和准确提示词见 web/themes/assets/campus-prompts.json，处理原稿存于仓库外 UI设计探索/20261018-校园蓝白轮播。

首页与时间表各自在页面末尾挂载一处组件。设置 → 外观可分别开关位置、自动轮播，并选择 10／20／30／60 秒间隔，默认 20 秒。图片进入可见区域才请求首图并启动；离屏、后台标签页、鼠标停留、键盘焦点或减少动态效果都会停表。手动前后切换后保持暂停，可用播放按钮恢复。控制按钮支持键盘、可见焦点及 44px 触控尺寸，触屏始终显示；桌面鼠标悬停或键盘焦点进入时显示。

五张 WebP 共约 716KiB，不预加载全组；固定容器尺寸，双图层淡入，不覆盖课程格、表单或正文。加载失败保持当前图片，并有界尝试其余图片；清理移除计时器、观察器、全局监听器，并拒绝迟到的图片回调。偏好仍使用 campus.appearance.v1，保存到 options[主题ID].moments 与 options[主题ID].rotation；旧版根级字段自动迁移到两套蓝白主题，保留原有每页开关和间隔，不影响 PRTS 或自定义主题选项。

实现位于 web/themes/campus-moments.js、campus-moments.css；两个业务模块仅在观星台／星夜手记主题的页面末尾调用；Default、PRTS 与其他主题不挂载。样式由两套蓝白主题的 theme.json 注册，不全局引入。checks/check_campus_moments.mjs 用合成 DOM 和可控时间验证轮播、暂停、可见性、减动态、错误跳过及卸载，不接触真实账号。

## 侧边栏微调

web/themes/campus-rail.css 增加细坐标轴、圆点、选中短刻度和品牌分隔线；沿用 228px 宽度、46px 导航目标、名称与模块顺序。两主题辅助文字最低抽查对比度 5.10:1，提供减少动态和 forced-colors 处理。手机菜单和原有路由逻辑不变。

观星台夜间配色使用独立 CSS 变量与限定选择器，覆盖阅读区、主按钮、表单、弹窗和按院系着色的课表卡。checks/check_observatory_contrast.mjs 校验真实主题 token 与语义混色，普通文字最低 4.58:1，输入边界至少 3:1。完整统一检查通过 48 项 Python、7 项 JavaScript、Windows 启动器与 68 项 JavaScript 语法；浏览器核对夜间对话欢迎区、课表弹窗、表单及 375px 无横向溢出，两密码按钮实际 44×44px。


## 双语文案与场景

首页保留古典雕塑与天文主图，大标题从 web/themes/home-slogans.js 的六组中英文 Slogan 随机选取：校园系统、信息寻宝、系统并非答案、学校网页、耐心与系统数量、班群与课程大纲。两套蓝白主题及空白对话复用同一选择；本页内保持稳定，刷新时避开上一条，也避开本页下方通用短句的相同英文。sessionStorage 只记录 Slogan ID，不保存问题或成绩。长句按语义分成普通字重与强调色两段，容器随内容增高，中文保留，窄屏不会截断。开始对话按钮只进入输入状态，不发送消息。首页主图下方直接显示一组轻量的英文／中文语句；进入对话后，输入区下方也一直显示，不再依赖历史消息或测试草稿。开始输入后收起欢迎图，短句仍然保留。原有资料发送说明、AI 配置状态和发送提示继续显示，不能用装饰语句替代。

文案从用户提供的语料中人工筛选，内置于 web/themes/campus-copy.js，分为通用、成绩、截止事项、课表与资料五组。只有用户明确输入相关话题时才选对应组；不能从助手回答推断用户 GPA，不能把某个学期周次、深夜时刻或“已读完资料”当成已知事实。非空恢复草稿优先，否则依据会话最近一条用户消息；其余情况使用通用组。关键词识别只用于展示，不影响 AI 路由、回答或数据获取。

每次打开或刷新页面时，各类话题首次显示都会重新随机选取一组；有多条候选时避开上次显示的文案，成绩和资料等单句话题仍显示原句。同一次页面打开期间保持稳定，不定时滚动、不随逐字输入闪换。失焦、选常用问题或切换会话时可按明确话题更新。sessionStorage 只保存各话题上次显示的文案 ID，用于刷新时避免重复，不保存问题正文或成绩；存储不可用时仍会随机选取，并在当前页面内存中保持稳定，但无法排除上次页面的选择。英文 16px、中文 14px，窄屏英文 15px；使用主题文字色和自然换行。

顶部原中文开场白只在观星台与星夜手记启用。主题展示入口必须显式导出 openingLines = true 才开启；Default、PRTS、以后新增主题及加载失败回退默认隐藏，初次 HTML 也隐藏以避免闪现。新首页与页脚通过 assistant.home / assistant.footer 主题 slot 实现，业务模块只传入白名单话题，其他主题不插入这些内容。

针对检查增加 check_campus_copy.mjs（稳定选择、转义、存储拒绝、话题隔离）和 check_study_copy.mjs（中英文显式话题、草稿优先、排除助手消息），主题检查覆盖缺省隐藏和严格 boolean 开启。浏览器核对四主题、1440px、375px、320px 与 900×480 短横屏；没有发送真实问题或调用付费模型。本次完整统一检查通过 48 项 Python、9 项 JavaScript、Windows 启动器与 72 项 JavaScript 语法检查。


## 课表同步后的显示兼容

保留简约四周作业表和本周课程格；桌面端在本周详情里提供默认收起的“其他安排与截止”，按日期显示非节次项目，沿用原有筛选与详情／编辑入口。已在课程格里的节次项目不重复，刷新保留折叠选择，手机仍使用原列表。观星台的“今天”徽标局部使用 12px 深色文字，对比度 7.63:1；其他主题不覆盖。`checks/check_timetable_visibility.mjs` 用真实渲染器和合成数据验证这些边界。


## 外观重开恢复

外观选择、每主题人物与自定义偏好保存到本机服务的独立普通设置，浏览器仅作缓存。相同本地实例的127.0.0.1、localhost和系统浏览器读取同一外观；首次只迁移真实存在的旧浏览器选择，空浏览器不会用Default覆盖已有值。显式局部修改按版本保存，避免另一页面旧状态覆盖无关主题选项；修改端口不清空外观。缺失主题仍保留原选择，并临时使用Default。

顶部中文开场白与双语内容的主题白名单保持不变。首页随机主句避开当前通用短句；清空输入、刷新和重新从run.cmd打开均不再隐藏通用双语短句。
