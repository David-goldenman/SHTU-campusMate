校园里的信息分散在教务、Blackboard、Gradescope、Piazza、邮箱和群消息里。campusMate 把这些资料按课程与时间整理在一起，让你更容易知道今天要做什么、接下来去哪儿，以及复习时该从哪里开始。

## 一个工作台，串起一天的学习

| 场景 | campusMate 可以帮你做什么 |
| --- | --- |
| 打开首页 | 查看近期作业、截止日期和今明日安排，接着向学习助手提问 |
| 管理课程 | 按本学期课程整合各平台的作业、公告、课件与录播资料 |
| 安排时间 | 在每周时间表查看课程、考试、Quiz、展示和活动，编辑或删除个人安排 |
| 阅读邮件 | 按偏好分类重点邮件与兴趣活动，保留正文排版，查看日总结和周总结 |
| 跟进通知 | 集中查看学习事项与活动建议，明确确认参加后加入时间表 |
| 找到下一站 | 在校园地图定位课程地点、查看室外步行路线和课间行程建议 |
| 整理群消息 | 接入本人本机的微信与 QQ 消息，按群和课程整理带原文依据的事项 |

已连接来源的同步在后台继续，切换页面后可以接着查看进度和结果。已保存的连接、偏好与聊天记录可在重启后恢复；学校会话到期时仍需重新验证。

## 能结合学习资料的 AI 助手

学习助手基于官方 DeepSeek Harness 运行，按问题查询已连接资料，并给出带来源的回答。你可以直接问：

- “这周还有哪些作业没完成？按截止日期帮我安排一下。”
- “做这次实验之前应该复习什么？帮我找到课件对应的页码。”
- “结合已修课程和培养方案，我想往这个方向发展，后续选课怎么安排？”

PDF 与 PPTX 资料支持按页提取文字和引用，扫描件可配置图片识别或本地 OCR。对话支持 Markdown、流式回复，以及按账号保存的新建、切换、归档和删除历史对话。模型可选择 DeepSeek 或其他已支持的提供商。

后台助手会在资料更新后检查服务状态、整理重要事项并提出建议。形策、心理活动和讲座等安排由用户明确确认参加后加入时间表，已删除的同一活动保留用户的选择。

## 四种界面，保留你的习惯

默认界面沿用 Nord 配色，提供清楚的分区、紧凑列表与适合长文阅读的布局。也可以在设置中切换到观星台、星夜手记或 PRTS · 学习终端；主题选择会保留到下次打开。

## 资料在本地，AI 使用范围清楚可见

账号凭据和模型 API Key 在本机加密保存，聊天记录、设置和学习资料保存在本地。使用 AI 时，回答所需的资料会发送至你选择的模型服务；连接哪些来源、采用哪些偏好和参加哪些活动，都由你决定。

校园地图的步行路线依据已收录的室外道路估算，通行情况以现场为准。课程、考试与活动要求以原始来源为依据，回答和提醒保留可核对的资料入口。

## 开始使用

Windows 桌面安装包支持选择安装目录，携带所需运行环境。安装后打开 CampusMate，在设置中连接校园服务并配置 AI；用户数据、缓存和日志保存在安装目录的 `.private/`。下载见 [GitHub Releases](https://github.com/David-goldenman/Shanghaitech-2026-Hackthon/releases)。

源码运行继续使用 `run.cmd`。桌面安装、升级与构建见 [桌面说明](packaging/electron/README.md)。

安装、启动和配置见 [使用指南](docs/PROJECT_GUIDE.md#启动)；品牌图标与宣传素材见 [品牌介绍](docs/BRAND.md)。
